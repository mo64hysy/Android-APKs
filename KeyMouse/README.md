# KeyMouse

AndroidスマートフォンをBluetooth HIDキーボード・マウスとして使うアプリです。

## レイアウト
- キーボード：全面キーボード
- ノーマル：キーボード＋トラックパッド
- センター：左キーボード＋中央トラックパッド＋右キーボード
- ゲーミング：左キーボード＋トラックパッド

## 動作条件と注意
- Android 9（API 28）以上が必要です。
- Bluetooth HID Deviceに対応した端末が必要です。Androidのバージョンだけで対応が保証されるわけではありません。
- 接続先との初回ペアリングは、必要に応じてAndroidのBluetooth設定から行ってください。
- 実機での接続・入力試験は、APKのビルド成功とは別に必要です。
