# Gboard 長押しフリック改造

Gboard をベースに、300ms の長押し後にフリック方向で数字・記号を入力する機能を追加するプロジェクトです。

## 方針

- 改造対象は Gboard。別IMEへの置き換えは目的にしない。
- 通常のタップ・フリック・日本語変換を可能な限り維持する。
- 長押しフリックの変換ルールは `mapping.csv` に分離し、追加・変更しやすくする。
- 未登録方向は何も入力しない。
- 方向判定・タッチ処理・表示処理を分離する。
- 元の Gboard APK はこのリポジトリに再配布しない。ビルド時に利用者が用意したベース APK、または利用条件を確認した取得元から取得した APK を使う。

## ベースプロジェクト

参考元: https://github.com/gkpln3/Gboard-Patched

参考元には `Gboard_base.apk` と解析済み `Gboard_base/`、Apktool による再構築手順があります。これは完成済みの長押しフリック版ではありません。Gboard のバージョンや署名チェック処理に依存するため、まずベース APK のバージョン・構造を確認してからパッチを実装します。

参考元の README では、パッケージ名変更と署名チェックへの対応が必要と説明されています。参考元の MIT ライセンスは同リポジトリのパッチ用コードに関するものであり、Google の Gboard 本体やリソースの再配布許可を意味しません。

## 長押しフリック仕様

- 長押し判定: 300ms
- 長押し後に指を動かし、離した方向に対応する文字を入力
- 中央は移動せずに離した場合
- 未登録方向は入力しない
- 通常入力は従来どおり維持する
- 変換ルールは `mapping.csv` で管理する
- キー表示は中央に元のかな、周囲に対応する出力文字を小さく表示する
- 左右のみ登録されている場合は左右の2方向、上下のみの場合は上下の2方向として角度判定する

## ファイル

- `mapping.csv`: 元のかなと長押しフリック出力の対応表
- `README.md`: プロジェクト仕様・開発方針

## 実装予定の分割

1. ベース APK と Apktool の解析・再構築手順を固定
2. キーのタッチイベントから長押し状態を検出
3. 300ms 経過後に長押しフリックモードへ切り替え
4. 移動方向・距離・角度から方向を判定
5. `mapping.csv` を読み込む変換テーブルを実装
6. キー中央・周囲に小さな出力文字を描画
7. 通常入力との競合、誤入力、実機動作を検証

## 状態

初期セットアップ。変換仕様と対応表を配置済み。Gboard 内部のタッチ処理・描画処理へのパッチは、ベース APK の構造を確認してから実装します。
