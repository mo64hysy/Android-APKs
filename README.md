# Android APKs

Androidアプリのソースコードとビルド済みAPKをまとめるリポジトリです。

## アプリ一覧

- [Splatoon3Stats](./Splatoon3Stats/README.md) — イカリング3の表示テキストを取得してGPT向けに共有する試作アプリ
- [KeyMouse](./KeyMouse/README.md) — AndroidスマートフォンをBluetoothキーボード・マウスにする試作アプリ

## APKの入手

各アプリのAPKは [GitHub Actions](../../actions) のビルド成果物、または [Releases](../../releases) から取得します。

## ビルド

各アプリはGitHub ActionsでAndroid APKをビルドします。
